How this works

        
1. Import sales
Export your POS's Receipts CSV or Excel file and drop it on the Import tab — it's recognised automatically. Any other POS's file can be mapped manually.

        
2. Issue the right Mushak
Open any sale and click Generate to issue a tax invoice — Mushak 6.3 by default, or 6.10 for sales over Tk 2,00,000 (set your universal default in Settings, change it per invoice any time). Issue a Mushak 6.7 credit note against a sale, or record a Mushak 6.6 VDS certificate when a buyer withholds VAT.

        
3. Keep registers current
Log purchases for input VAT. The Registers tab keeps a running Mushak 6.1 purchase book and Mushak 6.2 sales book automatically, printable any time.

        
4. Daily & monthly reporting
The Daily report tab gives a same-day VAT snapshot. The Monthly return tab prepares a Mushak 9.1 worksheet you can use when filing at vat.gov.bd.

        
5. Hand off to your accountant
Export CSV, Excel, PDF, or a full JSON backup from the Export tab any time.
