Set up Yarding for your yard

Yarding is a purpose-built tool for complete ship yard accounting. One-time setup connects this device to your Supabase project. If your yard is already set up, connecting here will detect that automatically and take you straight to login instead of creating anything new.

Found in your Supabase project → Settings → API. Use the anon public key, never the service role key.
This app protects itself with a 6-digit access code, not a Supabase login — so anyone with your Supabase anon key and URL could in principle read the raw database directly. Keep those two values private, and treat this like an internal tool, not a public-facing one.

Your database isn't set up yet. Open your Supabase project → SQL Editor → paste the script below → Run. Then come back and press Continue.

Set your two access codes. Staff can record sales, expenses and payments. Admin can also edit ships, items, accounts and void entries. Use two different 6-digit codes — you'll type these to log in, no username needed.
